# Contributing to Sea Warfare

Contributions are welcome! Whether it's a bug fix, an improvement, or a new feature, your help is appreciated.

## How to Contribute

1. Fork the repository.
2. Create a branch for your changes.
3. Implement your changes and add or update tests when appropriate.
4. Run the test suite to make sure everything passes:

   ```bash
   npm test
   ```

5. Push your branch to your fork.
6. Open a Pull Request against the `main` branch of this repository.

## Pull Requests

Please provide a clear description of your changes, including:

- What was changed.
- Why the change is needed.
- Any relevant screenshots for UI changes.

Pull Requests will be reviewed before being merged. Please keep changes focused and related to a single purpose whenever possible.

## Questions and Suggestions

If you have an idea, find a bug, or want to discuss a possible improvement, feel free to open a GitHub Issue.

Thank you for helping improve Sea Warfare!
